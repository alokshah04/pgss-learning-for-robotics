Part I Check for Understanding

Basic notation and ideas from this week. Make sure you're comfortable with these before moving on.

Exercise 1 — Functions

Let $f(x) = x^2 + 2x + 1$. Compute:

  1. $f(0)$
  2. $f(1)$
  3. $f(2)$
  4. $f(-1)$
Solution
  1. $f(0) = 0 + 0 + 1 = 1$
  2. $f(1) = 1 + 2 + 1 = 4$
  3. $f(2) = 4 + 4 + 1 = 9$
  4. $f(-1) = 1 - 2 + 1 = 0$

Exercise 2 — Derivatives

For each function, compute the derivative.

  1. $f(x) = x^2$
  2. $f(x) = 3x^2$
  3. $f(x) = x^2 + 5x$
  4. $f(x) = (x-4)^2$
Solution
  1. $f'(x) = 2x$
  2. $f'(x) = 6x$
  3. $f'(x) = 2x + 5$
  4. $f'(x) = 2(x-4)$

Exercise 3 — Loss Minimization

Let $L(\theta) = (\theta - 5)^2$.

  1. What value of $\theta$ minimizes the loss?
  2. Compute $L(0)$, $L(5)$, $L(10)$.
  3. Compute $L'(\theta)$ and $L'(0)$.
  4. If $\theta = 0$, should gradient descent increase or decrease $\theta$?
Solution
  1. $\theta = 5$ minimizes the loss (it equals $0$ there).
  2. $L(0) = 25$, $\;L(5) = 0$, $\;L(10) = 25$.
  3. $L'(\theta) = 2(\theta-5)$, so $L'(0) = -10$.
  4. Since $L'(0) < 0$, the update $\theta \leftarrow \theta - \alpha L'(\theta)$ subtracts a negative number — it increases $\theta$ toward $5$.

Exercise 4 — One Step of Gradient Descent

Let $L(\theta) = (\theta-3)^2$, $L'(\theta) = 2(\theta-3)$. Start at $\theta = 0$, learning rate $\alpha = 0.1$.

  1. What is $L'(0)$?
  2. What is $\theta$ after one update?
  3. Did $\theta$ move closer to $3$?
Solution
  1. $L'(0) = 2(0-3) = -6$.
  2. $\theta \leftarrow 0 - 0.1(-6) = 0.6$.
  3. Yes — moved from $0$ to $0.6$, closer to $3$.

Exercise 5 — Vector Addition

Compute:

$$\begin{bmatrix}1\\4\end{bmatrix} + \begin{bmatrix}3\\-2\end{bmatrix}$$
Solution
$$\begin{bmatrix}1\\4\end{bmatrix} + \begin{bmatrix}3\\-2\end{bmatrix} = \begin{bmatrix}1+3\\4+(-2)\end{bmatrix} = \begin{bmatrix}4\\2\end{bmatrix}$$

Exercise 6 — Robot Position Update

A robot is at $p = \begin{bmatrix}2\\5\end{bmatrix}$ and moves by $\Delta p = \begin{bmatrix}3\\-1\end{bmatrix}$. What is the new position?

Solution
$$p + \Delta p = \begin{bmatrix}2\\5\end{bmatrix} + \begin{bmatrix}3\\-1\end{bmatrix} = \begin{bmatrix}5\\4\end{bmatrix}$$

Exercise 7 — Dot Product

Compute:

$$\begin{bmatrix}2\\3\end{bmatrix}^\top \begin{bmatrix}4\\-1\end{bmatrix}$$
Solution
$$2(4) + 3(-1) = 8 - 3 = 5$$

Exercise 8 — Linear Model Prediction

Let $\hat{y} = w^\top x + b$ with $w = \begin{bmatrix}2\\-1\end{bmatrix}$, $x = \begin{bmatrix}3\\4\end{bmatrix}$, $b = 5$. Compute $\hat{y}$.

Solution

$w^\top x = 2(3) + (-1)(4) = 6 - 4 = 2$, then $\hat{y} = 2 + 5 = 7$.

Exercise 9 — Norm

Compute $\left\|\begin{bmatrix}6\\8\end{bmatrix}\right\|_2$.

Solution
$$\sqrt{6^2 + 8^2} = \sqrt{36+64} = \sqrt{100} = 10$$

Exercise 10 — Probability Distribution

$X$ takes values $0, 1, 2$ with $P(X=0)=0.2$, $P(X=1)=0.5$, $P(X=2)=0.3$.

  1. Do these probabilities add to $1$?
  2. Most likely outcome?
  3. Least likely outcome?
Solution
  1. Yes: $0.2 + 0.5 + 0.3 = 1$.
  2. $X = 1$ (probability $0.5$).
  3. $X = 0$ (probability $0.2$).

Exercise 11 — Expected Value

Using the distribution from Exercise 10, compute $\mathbb{E}[X]$.

Solution
$$\mathbb{E}[X] = 0(0.2) + 1(0.5) + 2(0.3) = 0 + 0.5 + 0.6 = 1.1$$

Exercise 12 — Expected Reward

A robot gets reward $10$ on success and $0$ on failure, with success probability $0.6$.

  1. Expected reward?
  2. What if success probability is $0.9$?
  3. What if success reward is $20$ but probability stays $0.6$?
Solution
  1. $10(0.6) + 0(0.4) = 6$.
  2. $10(0.9) + 0(0.1) = 9$.
  3. $20(0.6) + 0(0.4) = 12$.

Exercise 13 — Sample Average

A robot runs 6 trials with rewards $1, 1, 0, 1, 0, 1$.

  1. What is the sample average reward?
  2. What does this estimate?
Solution
  1. $$\frac{1+1+0+1+0+1}{6} = \frac{4}{6} = \frac{2}{3} \approx 0.667$$
  2. It estimates the expected reward $\mathbb{E}[R]$.

Exercise 14 — Dataset Notation

Let $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^{100}$.

  1. How many examples?
  2. What does $x_i$ represent?
  3. What does $y_i$ represent?
  4. What is the goal of supervised learning?
Solution
  1. 100 examples.
  2. $x_i$ is the input for example $i$.
  3. $y_i$ is the label/target for example $i$.
  4. Find $f_\theta$ such that $f_\theta(x_i) \approx y_i$ — and generalize to new examples.

Exercise 15 — Regression vs. Classification

For each task, say whether it is regression or classification.

  1. Predicting house price.
  2. Predicting cat vs. dog in an image.
  3. Predicting tomorrow's temperature.
  4. Predicting whether a robot grasp succeeds or fails.
  5. Predicting the next motor command as a real number.
Solution
  1. Regression (price is a number).
  2. Classification (discrete category).
  3. Regression (temperature is a number).
  4. Classification (success/failure is discrete).
  5. Regression (motor command is a real number).
Part II Applications to Machine Learning

More guided exercises showing how this week's math appears in real ML and reinforcement learning. These connect directly to topics in Weeks 2 and 3.

Exercise 16 — Gradient of a Log Probability

In ML and RL we often encounter $\nabla_\theta \log f_\theta(x)$, where $f_\theta(x) > 0$. This appears when $f_\theta(x)$ is a policy probability $\pi_\theta(a \mid s)$.

  1. Using the chain rule, compute $\nabla_\theta \log f_\theta(x)$.
  2. Fill in the identity: $\nabla_\theta \log f_\theta(x) = \dfrac{?}{?}$
  3. Why is this identity useful when $f_\theta(x)$ is a probability?
Solution
  1. By the chain rule: $\nabla_\theta \log f_\theta(x) = \dfrac{1}{f_\theta(x)}\nabla_\theta f_\theta(x)$.
  2. $$\nabla_\theta \log f_\theta(x) = \frac{\nabla_\theta f_\theta(x)}{f_\theta(x)}$$
  3. Differentiating through probabilities directly can cause numerical underflow. Log-probabilities avoid this. This identity is fundamental to policy gradient methods, where we compute $\nabla_\theta \log \pi_\theta(a \mid s)$ to improve the policy.

Exercise 17 — Linear Regression from Maximum Likelihood

Suppose $y_i = w^\top x_i + \epsilon_i$ where $\epsilon_i \sim \mathcal{N}(0,\sigma^2)$, so $y_i \mid x_i,w \sim \mathcal{N}(w^\top x_i, \sigma^2)$.

  1. What does mean-zero noise mean intuitively?
  2. If $\sigma^2$ is small, do data points lie close to or far from the line?
  3. Write the full IID likelihood as a product.
  4. Take the log-likelihood; drop constants independent of $w$.
  5. Show that maximizing log-likelihood is equivalent to minimizing $\sum_i(y_i - w^\top x_i)^2$.
  6. When should linear regression work well? When might it fail?
Solution
  1. Noise is not systematically biased — it averages to $0$ over many samples.
  2. Close to the line.
  3. $$\prod_{i=1}^n p(y_i \mid x_i, w) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(y_i - w^\top x_i)^2}{2\sigma^2}\right)$$
  4. Log-likelihood $= \sum_i\left[-\frac{(y_i - w^\top x_i)^2}{2\sigma^2}\right]$ (dropping the constant $\log\frac{1}{\sqrt{2\pi\sigma^2}}$).
  5. Maximizing this expression is equivalent to minimizing $\sum_i(y_i - w^\top x_i)^2$, since $-\frac{1}{2\sigma^2} < 0$ flips the sign.
  6. Works well: approximately linear relationship; mean-zero small noise; IID data; matching train/test distributions. Fails: highly nonlinear truth; biased noise; distribution shift.

Exercise 18 — Understanding Softmax

A model outputs logits $z = \begin{bmatrix}2\\1\\0\end{bmatrix}$. Use $e^2 \approx 7.39$, $e^1 \approx 2.72$, $e^0 = 1$.

  1. Why can't we interpret logits directly as probabilities?
  2. Compute the softmax denominator $\sum_j e^{z_j}$.
  3. Compute all three softmax probabilities.
  4. Verify they sum to $1$.
  5. Using $\frac{\partial s_i}{\partial z_k} = s_i(\mathbf{1}_{i=k} - s_k)$, compute $\frac{\partial s_1}{\partial z_1}$ and $\frac{\partial s_1}{\partial z_2}$.
  6. What is the main intuition of the softmax gradient?
Solution
  1. Logits can be negative, exceed $1$, and don't sum to $1$.
  2. $7.39 + 2.72 + 1 = 11.11$.
  3. $s_1 \approx 0.665$, $s_2 \approx 0.245$, $s_3 \approx 0.090$.
  4. $0.665 + 0.245 + 0.090 = 1.000$ ✓
  5. $\frac{\partial s_1}{\partial z_1} = s_1(1-s_1) \approx 0.223$. $\quad\frac{\partial s_1}{\partial z_2} = -s_1 s_2 \approx -0.163$.
  6. Increasing one logit raises that class's probability and lowers all others'. Softmax couples classes together — a key property for classification and stochastic policies.

Exercise 19 — Softmax, Overflow, and Log-Sum-Exp

Computing $e^{z_i}$ directly for large $z_i$ causes overflow. The key insight: softmax is shift-invariant — subtracting any constant $c$ from all logits leaves the output unchanged.

Part A — Overflow Fix

Let $z = \begin{bmatrix}1000\\1001\\1002\end{bmatrix}$, $c = \max_i z_i$.

  1. What is $c$?
  2. What is $z - c$?
  3. Why is this safer?

Part B — Log-Sum-Exp

Use $e^{-2}\approx 0.135$, $e^{-1}\approx 0.368$, $e^0=1$ to estimate $\log\sum_j e^{z_j}$ via $c + \log\sum_j e^{z_j-c}$.

Solution

Part A

  1. $c = 1002$.
  2. $z - c = \begin{bmatrix}-2\\-1\\0\end{bmatrix}$.
  3. The largest exponent is now $e^0=1$ instead of $e^{1002}$. Safe for floating-point.

Part B

$$1002 + \log(e^{-2}+e^{-1}+e^0) \approx 1002 + \log(0.135+0.368+1) = 1002 + \log(1.503) \approx 1002.41$$

The point: we never computed $e^{1002}$ directly.

Exercise 20 — The Markov Assumption and Trajectory Probabilities

A trajectory is $\tau = (s_0,a_0,s_1,a_1,\ldots,s_T)$. The Markov assumption: $P(s_{t+1}\mid s_0,a_0,\ldots,s_t,a_t) = P(s_{t+1}\mid s_t,a_t)$.

  1. In words, what does the Markov assumption mean?
  2. Write $P(s_0,a_0,s_1,a_1,s_2)$ using the chain rule.
  3. Simplify using the Markov assumption and policy notation $\pi(a_t\mid s_t)$.
  4. Write the general trajectory probability $P(\tau)$.
Solution
  1. The next state depends only on the current state and action — not the full history.
  2. $$P(s_0)\,P(a_0\mid s_0)\,P(s_1\mid s_0,a_0)\,P(a_1\mid s_0,a_0,s_1)\,P(s_2\mid s_0,a_0,s_1,a_1)$$
  3. $$p(s_0)\,\pi(a_0\mid s_0)\,P(s_1\mid s_0,a_0)\,\pi(a_1\mid s_1)\,P(s_2\mid s_1,a_1)$$
  4. $$P(\tau) = p(s_0)\prod_{t=0}^{T-1}\pi(a_t\mid s_t)\,P(s_{t+1}\mid s_t,a_t)$$

    This factorization is the central object in RL.

Exercise 21 — Importance Sampling

We want $\mathbb{E}_{x\sim p}[f(x)]$ but only have samples from $q$. The identity:

$$\mathbb{E}_{x\sim p}[f(x)] = \mathbb{E}_{x\sim q}\!\left[\frac{p(x)}{q(x)}f(x)\right]$$

Let $p(A)=0.8$, $p(B)=0.2$, $q(A)=q(B)=0.5$, $f(A)=10$, $f(B)=0$.

  1. Compute $\mathbb{E}_{x\sim p}[f(x)]$ directly.
  2. Compute importance weights $p(A)/q(A)$ and $p(B)/q(B)$.
  3. Compute $\mathbb{E}_{x\sim q}[p(x)/q(x)\cdot f(x)]$.
  4. Do the two answers match?
  5. Why is this useful in RL?
Solution
  1. $0.8(10)+0.2(0) = 8$.
  2. $p(A)/q(A) = 1.6$, $\;p(B)/q(B) = 0.4$.
  3. $0.5(1.6)(10)+0.5(0.4)(0) = 8$.
  4. Yes — both equal $8$.
  5. In RL, trajectories come from an old policy $q$. Importance sampling lets us evaluate a new policy $p$ without re-running it. Powerful, but can be unstable when $p(x)/q(x)$ is very large.

Exercise 22 — Connecting Softmax to Policies

A robot has three actions (left, right, forward). A network outputs logits $z = \begin{bmatrix}1\\3\\2\end{bmatrix}$. Use $e^1\approx2.72$, $e^2\approx7.39$, $e^3\approx20.09$.

  1. Compute the softmax denominator.
  2. Compute $\pi(\text{left}\mid s)$, $\pi(\text{right}\mid s)$, $\pi(\text{forward}\mid s)$.
  3. Which action is most likely?
  4. Why prefer a stochastic policy over always choosing the most likely action?
Solution
  1. $2.72+20.09+7.39 = 30.20$.
  2. $\pi(\text{left})\approx 0.090$, $\;\pi(\text{right})\approx 0.665$, $\;\pi(\text{forward})\approx 0.245$.
  3. Right (probability $\approx 0.665$).
  4. Stochastic policies enable exploration — the robot occasionally tries suboptimal actions and may discover better ones. Always being greedy can trap the agent at suboptimal behavior.
