Overview

The goal of this course is to understand how robots learn from data, feedback, and experience. By the end, you should understand the fundamentals of deep learning, reinforcement learning, and how these tools train not just robotic agents, but language models and other sequential decision-making systems.

This first week covers:

  • What robotics is and why it is hard.
  • Why learning-based approaches became important.
  • The mathematical tools we need: calculus, linear algebra, probability, and expectation.
  • The supervised learning paradigm.
  • Linear models, nonlinear models, neural networks, gradient descent, and backpropagation.
Disclaimer

These topics typically comprise a full semester course and take far longer to fully digest. We will omit much valuable content in the interest of time. The goal here is not mastery, but to provide enough vocabulary and intuition so that frontier-level machine learning no longer feels mysterious.

A Brief History of Robotics

What is a robot? Informally, a robot is a machine that can sense the world, make decisions, and act on the world.

It was popularized by the Czech writer Karel Čapek in his 1920 play R.U.R. Later, science fiction writers such as Isaac Asimov helped shape how people imagined robots.

For a long time — and even still — robotic systems were built by designing these components separately. Engineers would hand-design perception algorithms, planning algorithms, and controllers, then combine them.

Why is Robotics Hard?

  • Sensor noise — real sensor readings are always imperfect.
  • Nonstationary environments — the world changes in unpredictable ways.
  • Partial observability — the robot cannot always see the full state of the world.
  • Safety and latency constraints — mistakes can be costly; decisions must be fast.
  • Long-horizon tasks — some goals require many sequential decisions over time.
Moravec's Paradox

A CMU roboticist, Hans Moravec, once observed: "It is comparatively easy to make computers exhibit adult-level performance on intelligence tests or playing checkers, and difficult or impossible to give them the skills of a one-year-old when it comes to perception and mobility."

Why? Physical intelligence is extremely rich. Walking or grasping involves perception, balance, contact forces, motor control, and constant feedback — whereas a chess program reasons in a clean digital environment.

Where Does Learning Enter the Picture?

Instead of explicitly programming perception, planning, and control separately, we can use data to train the entire system end-to-end using deep learning.

Over the last few years, we've observed great strides in robotic capability. Several key developments — pretrain + finetune, action chunking, generative model control — enabled a wave of success that mostly exploits the benefits of scale (in model size, data, and compute).

So Why Study Robotics?

It's unclear why some recent advances work. Open problems include:

  • Opacity: Deep learning policies are opaque, unexplainable, and not robust to distribution shiftWhen the test environment differs from training. A model trained in one setting may fail badly in another..
  • Long-horizon performance: Reliable multi-step tasks remain slow and unreliable.
  • Safety and reliability: Real-world success is often much lower than demos suggest.
  • Continual learning: How do robots continually acquire new skills?
  • The data gap: Language models train on the entire internet; robots have orders of magnitude less data.
Key Claim

These problems are not specific to robotics — they are fundamental ML problems. Robotics is therefore an excellent testbed for pushing the frontier of ML.

Mathematical Prerequisites Review

The mathematical basis for machine learning sits at the intersection of statistics, calculus, and linear algebra.

Functions

A functionA rule that maps each input to exactly one output. Written $f: X \to Y$. takes an input and returns an output. For example:

$$f(x) = x^2$$

If $x = 3$, then $f(3) = 9$. In machine learning, a model is also a function:

$$\hat{y} = f(x)$$

Here $x$ is the input, $f$ is the model, and $\hat{y}$ (hat = "predicted") is the prediction. The true answer is $y$.

Derivatives

A derivativeMeasures how fast a function's output changes. Written $f'(x)$ or $\frac{df}{dx}$. tells us how fast a function changes. For $f(x) = x^2$:

$$f'(x) = 2x$$

The general power rule: for $f(x) = x^n$,

$$\boxed{f'(x) = nx^{n-1}}$$

The derivative gives the slope at a point. At $x=1$, $f'(1)=2$; at $x=5$, $f'(5)=10$ — steeper there.

Why derivatives matter in ML

We define a loss function$L(\theta)$ measures how wrong the model is. Lower = better. measuring how bad our model is, and we want to minimize it. If the loss is $L(\theta) = (\theta-3)^2$:

  • If $\theta=5$: $L'(5) = 4 > 0$ — loss increasing, so decrease $\theta$.
  • If $\theta=1$: $L'(1) = -4 < 0$ — loss decreasing, so increase $\theta$.

This is the core idea behind gradient descent.

Partial Derivatives

A partial derivativeDerivative w.r.t. one variable, holding others fixed. Written $\frac{\partial L}{\partial w}$. asks: how does the loss change if I change one parameter while holding others fixed? For $f(x) = wx + b$:

$$\frac{\partial L}{\partial w}, \qquad \frac{\partial L}{\partial b}$$

Gradients

A gradientVector of all partial derivatives. Points in the direction of steepest increase. Written $\nabla L(\theta)$. stacks all partial derivatives into a vector:

$$\nabla L = \begin{bmatrix} \dfrac{\partial L}{\partial w} \\[10pt] \dfrac{\partial L}{\partial b} \end{bmatrix}$$

The gradient points toward increasing loss. To minimize, move in the opposite direction:

Gradient Descent Update Rule
$$\theta \leftarrow \theta - \alpha \nabla L(\theta)$$

$\theta$ = all model parameters, $\alpha$ = learning rateControls step size. Too large → unstable. Too small → slow., $\nabla L(\theta)$ = gradient of loss.

Gradient descent on $L(\theta) = (\theta - 3)^2$. The ball rolls downhill toward the minimum.

Stationary Points

A stationary pointWhere $\nabla L(\theta) = 0$. Could be a minimum, maximum, or saddle point. is where the gradient is zero — the function is locally flat. A stationary point can be a minimum, a maximum, or a saddle pointMinimum in some directions, maximum in others. Common in high-dimensional loss landscapes..

In convexShaped like a bowl. Any local minimum is also the global minimum. problems, all stationary points are global minimizers. Many classical ML problems are convex. Deep learning is not — neural network loss landscapes are often nonconvex. Surprisingly, gradient-based methods still work very well. Understanding why is an open question.

Linear Algebra Review

Linear algebra is the mathematics of vectors and matrices. ML models operate on many numbers at once:

  • A robot state: position, velocity, joint angles, sensor readings.
  • An image: millions of pixel values.
  • A neural network: billions of parameters.

Scalars, Vectors, and Matrices

A scalarA single real number. is a single number. A vectorOrdered list of numbers. $x \in \mathbb{R}^n$ has $n$ entries. is a column of numbers:

$$x = \begin{bmatrix} 2 \\ 5 \end{bmatrix} \in \mathbb{R}^2, \qquad s = \begin{bmatrix} x \\ y \\ v_x \\ v_y \end{bmatrix} \in \mathbb{R}^4$$

A matrixRectangular array. $A \in \mathbb{R}^{m \times n}$ has $m$ rows and $n$ columns. is a rectangular array of numbers:

$$A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} \in \mathbb{R}^{2 \times 2}$$

Matrix–Vector Multiplication

Multiplying a matrix by a vector produces another vector. Each output entry is a dot product of a row with the input:

$$Ax = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} \begin{bmatrix} 5 \\ 6 \end{bmatrix} = \begin{bmatrix} 1\cdot5 + 2\cdot6 \\ 3\cdot5 + 4\cdot6 \end{bmatrix} = \begin{bmatrix} 17 \\ 39 \end{bmatrix}$$

In neural networks, layers compute $z = Wx + b$, where dimensions must be consistent:

$$\underbrace{z}_{\mathbb{R}^m} = \underbrace{W}_{\mathbb{R}^{m\times n}}\underbrace{x}_{\mathbb{R}^n} + \underbrace{b}_{\mathbb{R}^m}$$

Written entry-by-entry:

$$z_i = \sum_{j=1}^{n} W_{ij}\, x_j + b_i, \qquad i = 1,\ldots,m$$

Dot Products

The dot product$w^\top x = \sum_i w_i x_i$. Returns a scalar. Measures alignment. of two vectors:

$$w^\top x = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n$$

Example: $w=[2,3]^\top$, $x=[4,5]^\top$ gives $w^\top x = 8 + 15 = 23$. A linear model uses a dot product: $\hat{y} = w^\top x + b$.

Norms

A normSize of a vector. The Euclidean norm $\|x\|_2 = \sqrt{\sum_i x_i^2}$ is most common. measures vector size:

$$\|x\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_d^2}$$

Example: $\left\|\begin{bmatrix}3\\4\end{bmatrix}\right\|_2 = \sqrt{9+16} = 5$.

Matrix Calculus

When differentiating a scalar loss $L$ with respect to a parameter vector or matrix, the gradient has the same shape as the parameter:

  • $\theta \in \mathbb{R}^n \Rightarrow \nabla_\theta L \in \mathbb{R}^n$
  • $W \in \mathbb{R}^{m\times n} \Rightarrow \nabla_W L \in \mathbb{R}^{m\times n}$, where $(\nabla_W L)_{ij} = \frac{\partial L}{\partial W_{ij}}$

This shape-matching is what makes gradient descent well-defined regardless of model size.

A useful identity: if $L = \|y - Xw\|_2^2$, then $\frac{\partial}{\partial w}(Xw) = X^\top$ (think of $X$ as a linear map; its adjoint is $X^\top$). This gives $\nabla_w L = -2X^\top(y - Xw)$, as we will see in linear regression below.

Probability and Expectation

Probability is the mathematics of uncertainty — and robotics is full of it. A robot may not know exactly where an object is. A motor command may not produce the intended motion. Probability helps us reason about uncertain outcomes.

Random Variables

A random variableA variable determined by a random process. Written with capital letters, e.g. $X$. is a quantity whose value is uncertain. For example, let $X$ be the result of rolling a die — $X \in \{1,2,3,4,5,6\}$.

In robotics: next state, reward, sensor noise, grasp success, or action chosen by policy.

Probability Distributions

A probability distributionHow likely each outcome is. Probabilities are non-negative and sum to 1. assigns likelihoods to outcomes. For a fair die:

$$P(X = k) = \frac{1}{6}, \quad k \in \{1,2,3,4,5,6\}, \qquad \sum_x P(X=x) = 1$$

Conditional Probability

Conditional probability$P(A \mid B)$: probability of $A$ given $B$ has occurred. $P(A \mid B)$ reads "probability of $A$ given $B$." In robotics:

$$P(s' \mid s, a) \quad \text{— probability of next state $s'$ given current state $s$ and action $a$}$$

This notation reappears when we study Markov Decision Processes.

Bayes' Rule
$$P(A \mid B) = \frac{P(B \mid A)\, P(A)}{P(B)}$$

Lets us update belief about $A$ after observing evidence $B$. Foundational to probabilistic robotics, Bayesian filters, and much of modern ML.

Independence

Two random variables $X$ and $Y$ are independent$P(X,Y) = P(X)P(Y)$. Knowing one tells you nothing about the other. if:

$$P(X = x,\; Y = y) = P(X = x)\cdot P(Y = y) \quad \text{for all } x, y$$

Equivalently, $P(X \mid Y) = P(X)$ — knowing $Y$ gives no information about $X$. In ML, we often assume data are IIDIndependent and Identically Distributed. Each sample is drawn independently from the same distribution. (independent and identically distributed). This assumption is useful but not always true — its violation gives rise to distribution shift.

Expectation

The expectationProbability-weighted average. $\mathbb{E}[X] = \sum_x x\,P(X=x)$ for discrete $X$. is the average value of a random variable:

$$\mathbb{E}[X] = \sum_x x\, P(X = x)$$

For a fair die: $\mathbb{E}[X] = \frac{1+2+3+4+5+6}{6} = 3.5$. You can't roll a 3.5, but the long-run average converges there.

Linearity of Expectation

For any random variables $X$, $Y$ and constants $a$, $b$:

$$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$$

This holds even if $X$ and $Y$ are not independent — a remarkably useful fact. We will use it constantly when analyzing gradient estimators in reinforcement learning.

Sample Averages

If a robot tries a task 5 times with rewards $1, 0, 1, 1, 0$, the sample average is:

$$\hat{\mathbb{E}}[R] = \frac{1+0+1+1+0}{5} = 0.6$$

This estimates the expected reward — the core idea behind policy evaluation in RL.

Law of Large Numbers

As $n \to \infty$, the sample average converges to the true expectation:

$$\frac{1}{n}\sum_{i=1}^n X_i \;\xrightarrow{\;n\to\infty\;}\; \mathbb{E}[X]$$

This justifies using sample averages to estimate expectations — a trick we will use constantly in RL.

Variance

The variance$\text{Var}(X) = \mathbb{E}[(X-\mathbb{E}[X])^2]$. Measures spread. measures how spread out outcomes are:

$$\text{Var}(X) = \mathbb{E}\!\left[(X - \mathbb{E}[X])^2\right] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$
  • Strategy A: reward $10$ w.p. $0.5$, reward $0$ w.p. $0.5$. $\mathbb{E}=5$, high variance.
  • Strategy B: reward $5$ w.p. $1.0$. $\mathbb{E}=5$, zero variance.

Variance matters in robotics because we care about reliability, not just average performance.

The Gaussian (Normal) Distribution
$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

Fully characterized by mean $\mu$ and variance $\sigma^2$. Written $X \sim \mathcal{N}(\mu, \sigma^2)$. Appears everywhere in robotics: sensor noise, actuator uncertainty, stochastic policies.

Machine Learning Primer

Central Idea

Instead of explicitly programming a solution, we use data to fit a model.

A model is a function $\hat{y} = f_\theta(x)$, where $\theta$ are the parametersNumbers inside the model we adjust during training. Also called weights. we adjust during training.

Supervised Learning

In supervised learningLearning from labeled (input, output) pairs., we are given a dataset of input-output pairs:

$$\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n$$

The goal: find $f_\theta$ such that $f_\theta(x_i) \approx y_i$. For example, $x_i$ = robot camera image, $y_i$ = action a human demonstrator took.

Training and Test Sets

We split the data into disjoint sets:

$$\mathcal{D} = \mathcal{D}_{\text{train}} \cup \mathcal{D}_{\text{test}}, \qquad \mathcal{D}_{\text{train}} \cap \mathcal{D}_{\text{test}} = \emptyset$$

$\mathcal{D}_{\text{train}}$ fits the model; $\mathcal{D}_{\text{test}}$ evaluates it on unseen examples. The goal is not memorization — it is generalizationPerforming well on examples not seen during training..

Empirical Risk Minimization & Distribution Shift

Because training data is drawn IID, minimizing training loss should minimize test loss too. But in real life, data across deployment conditions is often not IID. When the test distribution differs from training, we face distribution shiftDifferent train/test distributions. Can cause dramatic performance drops. — an open research area.

Loss Functions

For regression, a common choice is squared error$(f_\theta(x)-y)^2$. Penalizes large errors heavily. Corresponds to Gaussian noise assumption.:

$$L(\theta) = \frac{1}{n}\sum_{i=1}^{n}\bigl(f_\theta(x_i) - y_i\bigr)^2$$
Why squared loss?

Smooth and differentiable everywhere. Probabilistic justification: minimizing squared loss equals maximum likelihood estimation under a Gaussian noise model. Penalizes large errors more than small ones.

Linear Regression

The simplest supervised model: $f_\theta(x) = w^\top x + b$. In matrix notation:

$$L(w) = \|y - Xw\|_2^2, \quad X \in \mathbb{R}^{n\times d},\; y \in \mathbb{R}^n,\; w \in \mathbb{R}^d$$

Solving via the Gradient

Expanding the loss: $L(w) = (y - Xw)^\top(y - Xw) = y^\top y - 2w^\top X^\top y + w^\top X^\top X w$.

Taking the gradient with respect to $w$ (using the identity $\nabla_w(w^\top X^\top X w) = 2X^\top X w$ for symmetric $X^\top X$, and $\nabla_w(w^\top X^\top y) = X^\top y$):

$$\nabla_w L = -2X^\top y + 2X^\top X w$$

Notice the shape: $X^\top \in \mathbb{R}^{d\times n}$ times $(y - Xw) \in \mathbb{R}^n$ gives $\nabla_w L \in \mathbb{R}^d$ — same shape as $w$, as required. Setting $\nabla_w L = 0$:

$$X^\top X w = X^\top y \quad \Longrightarrow \quad \boxed{w^\star = (X^\top X)^{-1} X^\top y}$$
Assumptions

This solution requires $X^\top X$ to be invertible (equivalently: the columns of $X$ are linearly independent, i.e. no redundant features). When $n < d$ (more features than data points), $X^\top X$ is rank-deficient. This and related issues are explored in the exercises.

Important Caveat

Linear regression is one of the rare ML problems with a closed-form solution. Most modern models cannot be solved this way — we use gradient descent instead.

Linear regression: gradient descent fitting a line to data. Watch the line rotate and translate toward the least-squares fit.

Limitations of Linear Models

Linear models work when the true relationship is roughly linear. But images, language, and robot motion are nonlinear.

A linear model (blue) fails to fit curved data. A more expressive model is needed.

Nonlinear Models and Feature Maps

One idea: transform the input with a feature map$\phi(x)$ maps raw inputs to a more useful representation. Then apply a linear model on top. $\phi(x)$, then fit a linear model:

$$f(x) = w^\top \phi(x), \quad \text{e.g. } \phi(x) = \begin{bmatrix}x \\ x^2\end{bmatrix}$$

This lets a linear model fit a curve. But: how do we choose $\phi$? For images and robotics, hand-designing features is extremely hard. This motivates neural networks.

Neural Networks

A neural networkComposed of linear layers and nonlinear activations. Can approximate any continuous function (Universal Approximation Theorem). learns its own features. A single layer:

$$h = \sigma(Wx + b)$$

The activation functionNonlinearity applied elementwise. Without it, stacking layers collapses to a single linear map. $\sigma$ is crucial — without nonlinearity, any stack of linear layers is still just a linear function. A common choice is ReLU:

$$\text{ReLU}(z) = \max(0, z)$$
Left: linear model — can only draw a line. Right: two-layer network with ReLU — can fit complex curves by composing bent lines.

A two-layer network:

$$f_\theta(x) = W_2\,\sigma(W_1 x + b_1) + b_2$$

By stacking many layers, neural networks represent very complicated functions — useful for images, language, and robotics.

Gradient Descent (for Neural Networks)

For neural networks we cannot solve for parameters directly. We iterate:

  1. Compute the loss.
  2. Compute the gradient $\nabla_\theta L(\theta)$.
  3. Update: $\theta \leftarrow \theta - \alpha \nabla L(\theta)$.
  4. Repeat.
Intuition

Imagine standing on a hilly landscape in the fog. You want the lowest point. You feel the slope under your feet and take a small step downhill, then repeat. The gradient tells you which direction is "uphill" — you step the other way.

Stochastic Gradient Descent (SGD)

Computing gradients over the full dataset is expensive. Instead we use a random mini-batchA small random subset of training data. Batch size $B$ is typically 32–512. of $B$ examples:

$$\hat{\nabla} L(\theta) = \frac{1}{B}\sum_{i=1}^{B} \nabla L_i(\theta)$$

This is an unbiased estimator of the full gradient. To see why:

$$\mathbb{E}\!\left[\hat{\nabla} L(\theta)\right] = \frac{1}{B}\sum_{i=1}^B \mathbb{E}\!\left[\nabla L_i(\theta)\right] = \nabla L(\theta)$$

where we used linearity of expectation and the fact that each $i$ is drawn IID. By the Law of Large Numbers, as $B \to \infty$ the estimate converges to the true gradient. SGD is noisy but much faster for large datasets. Modern networks use accelerated variants like Adam, accessed through PyTorch.

Core ML Training Loop
  1. Sample a random mini-batch $\{(x_i, y_i)\}_{i=1}^B \subset \mathcal{D}_{\text{train}}$.
  2. Forward pass: compute predictions $\hat{y}_i = f_\theta(x_i)$ for each $i$.
  3. Compute loss: $L = \frac{1}{B}\sum_{i=1}^B \ell(\hat{y}_i, y_i)$.
  4. Backward pass: compute gradients $\nabla_\theta L$ via backpropagation.
  5. Update: $\theta \leftarrow \theta - \alpha \nabla_\theta L$.
  6. Repeat until convergence.

Backpropagation

BackpropagationEfficient gradient computation using the chain rule. Runs in time proportional to the forward pass. computes gradients efficiently using the chain rule$\frac{dL}{dx} = \frac{dL}{dy}\cdot\frac{dy}{dx}$. Lets us differentiate through compositions..

Forward Pass

$$z^{(1)} = W_1 x + b_1, \quad h = \sigma(z^{(1)}), \quad z^{(2)} = W_2 h + b_2, \quad L = (z^{(2)} - y)^2$$

Backward Pass — Chain Rule

Working backward from $L$:

$$\frac{\partial L}{\partial z^{(2)}} = 2(z^{(2)} - y)$$
$$\frac{\partial L}{\partial W_2} = \frac{\partial L}{\partial z^{(2)}} \cdot h^\top, \qquad \frac{\partial L}{\partial b_2} = \frac{\partial L}{\partial z^{(2)}}$$
$$\frac{\partial L}{\partial h} = W_2^\top \cdot \frac{\partial L}{\partial z^{(2)}}$$
$$\frac{\partial L}{\partial z^{(1)}} = \frac{\partial L}{\partial h} \odot \sigma'(z^{(1)})$$
$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z^{(1)}} \cdot x^\top, \qquad \frac{\partial L}{\partial b_1} = \frac{\partial L}{\partial z^{(1)}}$$

where $\odot$ is elementwise multiplication and $\sigma'(z) = \mathbf{1}[z > 0]$ for ReLU. Notice the pattern: each layer only needs the gradient from the layer above it plus its own stored activations.

Backpropagation Algorithm
  1. Run the forward pass, storing all intermediate activations.
  2. Compute $\frac{\partial L}{\partial \hat{y}}$ at the output.
  3. For each layer $\ell$ from last to first: compute $\frac{\partial L}{\partial W_\ell}$, $\frac{\partial L}{\partial b_\ell}$, and pass $\frac{\partial L}{\partial h_{\ell-1}}$ backward.
  4. Collect all gradients and update parameters.
Computation graph for a two-layer network. Blue = forward pass (compute activations). Red = backward pass (propagate gradients via chain rule).

Modern libraries (PyTorch, JAX) build this graph automatically and run backprop for you.

Classification

So far we've discussed regression (predicting a number). Sometimes the output is a class: cat or dog? Move left, right, or forward?

Instead of a single number, the model outputs probabilities over classes using softmaxConverts raw scores (logits) into probabilities. $\text{softmax}(z)_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$. Outputs are positive and sum to 1.:

$$\text{softmax}(z)_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$$

For example, with three actions and raw scores $z = [1.2,\, 2.5,\, 0.8]$:

$$\pi = [\underbrace{0.2}_{\text{left}},\; \underbrace{0.7}_{\text{right}},\; \underbrace{0.1}_{\text{forward}}]$$

This idea reappears when we discuss stochastic policies in reinforcement learning.

Connections to Robotics

A robot policy$\pi(s)$ maps states to actions. The central object in RL. is a function:

$$a = \pi_\theta(s)$$

Learning means adjusting $\theta$ so the robot performs better.
