Part I Check Your Understanding

Short questions to make sure the basic vocabulary and definitions are clear.

Exercise 1 — MDP Components

An MDP is written as $(\mathcal{S}, \mathcal{A}, P, r, \gamma)$. For each object below, explain what it means in words, then give one robotics example.

  1. $\mathcal{S}$
  2. $\mathcal{A}$
  3. $P(s' \mid s, a)$
  4. $r(s, a)$
  5. $\gamma$
Solution
  1. $\mathcal{S}$ is the state space — the set of possible situations the robot can be in. Example: for a walking robot, the state might include body position, velocity, and joint angles.
  2. $\mathcal{A}$ is the action space — the set of possible actions the robot can take. Example: motor torques sent to the robot's joints.
  3. $P(s' \mid s, a)$ is the transition probability — how likely the robot is to reach state $s'$ after taking action $a$ in state $s$. Example: if a robot pushes an object, the object may move to a new location depending on friction and force.
  4. $r(s, a)$ is the reward function — a number telling the robot how good or bad an action was. Example: positive reward for moving forward, negative reward for falling.
  5. $\gamma \in [0,1)$ is the discount factor — it controls how much the robot values future rewards relative to immediate ones. Example: if $\gamma$ is close to $1$, the robot cares a lot about long-term walking performance.

Exercise 2 — Value, Q-Value, and Advantage

Explain each quantity in words.

  1. $V^\pi(s)$
  2. $Q^\pi(s, a)$
  3. $A^\pi(s, a)$

Then answer:

  1. If $A^\pi(s,a) > 0$, what should happen to the probability of taking action $a$ in state $s$?
  2. If $A^\pi(s,a) < 0$, what should happen?
Solution
  1. $V^\pi(s)$ is the value function: expected future reward if we start in state $s$ and follow policy $\pi$.
  2. $Q^\pi(s,a)$ is the action-value function: expected future reward if we start in state $s$, take action $a$, and then follow $\pi$ afterward.
  3. $A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$ is the advantage function: how much better or worse action $a$ is compared to the average action in state $s$.
  4. If $A^\pi(s,a) > 0$, the action was better than expected. The policy should increase the probability of taking $a$ in $s$.
  5. If $A^\pi(s,a) < 0$, the action was worse than expected. The policy should decrease the probability of taking $a$ in $s$.

Exercise 3 — Reward-to-Go

A trajectory receives rewards $r_0 = 1$, $r_1 = 2$, $r_2 = 3$. Assume $\gamma = 1$.

  1. What is the full trajectory return $R(\tau)$?
  2. What is the reward-to-go $G_0$?
  3. What is the reward-to-go $G_1$?
  4. What is the reward-to-go $G_2$?
  5. Why is reward-to-go better than assigning the full trajectory reward to every action?
Solution
  1. $$R(\tau) = r_0 + r_1 + r_2 = 1 + 2 + 3 = 6$$
  2. $G_0 = r_0 + r_1 + r_2 = 6$
  3. $G_1 = r_1 + r_2 = 5$
  4. $G_2 = r_2 = 3$
  5. An action at time $t$ cannot affect rewards that happened before time $t$. Reward-to-go credits each action only with the rewards it could have caused, which reduces noise in the gradient estimate.

Exercise 4 — Baselines

In policy gradient we often replace $G_t$ with $G_t - b(s_t)$, where $b(s_t)$ is a baseline.

  1. Does subtracting a baseline change the expected policy gradient?
  2. Why is it allowed?
  3. What does it help with?
  4. What is the most common baseline used in actor-critic methods?
Solution
  1. No — subtracting a baseline that depends only on the state does not change the expected gradient.
  2. Because:
    $$\mathbb{E}_{a \sim \pi(\cdot \mid s)}\!\bigl[\nabla_\theta \log \pi_\theta(a \mid s)\,b(s)\bigr] = 0$$
    The baseline is a constant with respect to the action, and the policy probabilities sum to 1.
  3. It reduces variance. The gradient estimate becomes less noisy.
  4. The value function: $b(s_t) = V^\pi(s_t)$. Then $G_t - V^\pi(s_t)$ is an estimate of the advantage $A^\pi(s_t,a_t)$.

Exercise 5 — Importance Sampling Ratio

Suppose data was collected under $\pi_{\theta_\text{old}}$, but we want to update $\pi_\theta$. The policy ratio is:

$$r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_\text{old}}(a_t \mid s_t)}$$

Explain what each case means:

  1. $r_t(\theta) = 1$
  2. $r_t(\theta) > 1$
  3. $r_t(\theta) < 1$
  4. Why can very large or very small ratios be dangerous?
Solution
  1. The new and old policies assign the same probability to action $a_t$ in state $s_t$.
  2. The new policy assigns higher probability to that action than the old policy did.
  3. The new policy assigns lower probability to that action than the old policy did.
  4. Very large or small ratios mean the new policy is very different from the old one. Old data may no longer represent what the new policy would do — importance sampling estimates become high-variance or misleading.

Exercise 6 — On-Policy versus Off-Policy

Explain the difference between on-policy and off-policy learning, then classify each example.

  1. You collect data from the current policy and immediately update that same policy.
  2. You train on demonstrations collected from a human expert.
  3. You use trajectories from an older version of your policy to update the newest policy.
  4. You collect data from a more exploratory policy but use it to improve a less random policy.
Solution

On-policy: learns from data collected by the same policy it is currently updating.
Off-policy: learns from data collected by a different policy.

  1. On-policy.
  2. Off-policy — data came from a human expert, not the current policy.
  3. Off-policy — data came from an older version of the policy.
  4. Off-policy — the behavior policy differs from the target policy being updated.
Part II RL Thinking Questions

Conceptual questions about why reinforcement learning is different from supervised learning and why algorithms like PPO are designed the way they are.

Exercise 7 — Why On-Policy REINFORCE Is Sample Inefficient

Suppose you run REINFORCE: collect a batch of trajectories under $\pi_{\theta_\text{old}}$, compute a gradient update, and get a new policy $\pi_\theta$.

  1. Why are the trajectories technically "old" after the update?
  2. In pure on-policy REINFORCE, why would we throw away those trajectories after one gradient step?
  3. Why is this sample inefficient?
  4. Why might we still want to reuse the data for a few gradient steps in practice?
  5. What can go wrong if we reuse it for too long?
Solution
  1. The trajectories were generated by $\pi_{\theta_\text{old}}$, not the updated policy $\pi_\theta$.
  2. The policy gradient estimator assumes data comes from the policy being updated. After one update, that is no longer exactly true.
  3. Collecting trajectories is expensive — it requires running a simulator or real robot. Discarding data after one gradient step wastes that effort.
  4. If the new policy is still close to the old one, the old data is still approximately valid and gives more signal per rollout.
  5. As the policy diverges from the one that collected the data, importance sampling ratios can explode. Gradient estimates become noisy or misleading, and the policy can destabilize. This is exactly why PPO clips the ratio.

Exercise 8 — Distribution Shift Thought Experiment

The old policy $\pi_{\theta_\text{old}}$ is cautious and visits safe states. The new policy $\pi_\theta$ is more aggressive and visits different states. Suppose you compute an update for $\pi_\theta$ using mostly trajectories from $\pi_{\theta_\text{old}}$.

  1. What distribution were the states and actions sampled from?
  2. What distribution do we actually care about improving?
  3. Why might old trajectories give a poor estimate of how the new policy behaves?
  4. What changes besides the action probabilities when the policy changes?
Solution
  1. States and actions were sampled from the distribution induced by $\pi_{\theta_\text{old}}$.
  2. We care about improving performance under the new policy $\pi_\theta$.
  3. The new policy may take different actions and therefore visit different states. Old data may not contain examples of what happens under the new policy.
  4. The state distribution changes too. Actions affect future states, so changing the policy changes not only which actions are chosen, but also which states the agent visits later.

Exercise 9 — Why Replay Buffers Need Fresh Data

In supervised learning, we can train on the same dataset for many epochs. In RL, suppose we keep a replay buffer of old trajectories.

  1. Why is old data more dangerous in RL than in supervised learning?
  2. What happens if the buffer contains mostly data from policies very different from the current policy?
  3. How can importance sampling help?
  4. Why doesn't importance sampling completely solve the problem?
  5. Why do we need to collect fresh data after some number of updates?
Solution
  1. In supervised learning the data distribution is fixed. In RL the data distribution depends on the policy — if the policy changes, the states and actions in the buffer may no longer match.
  2. The current policy is trained on states and actions it no longer visits. Gradients may not reflect what the current policy needs.
  3. Importance sampling reweights old data with ratios $r_t(\theta) = \pi_\theta / \pi_{\theta_\text{old}}$, correcting for the mismatch.
  4. Importance sampling can have high variance. If the ratio is very large, a few samples can dominate the estimate and make optimization unstable.
  5. The current policy induces a new state distribution. Fresh data tells us what states it actually visits and what rewards it receives — information old data cannot provide.

Exercise 10 — When Policy Gradients Struggle

Give an example of a robotics task where vanilla policy gradient methods would likely struggle. Your answer should address:

  1. Whether the reward is dense or sparse.
  2. What exploration requires.
  3. Why the gradient estimate might have high variance.
  4. Why many trajectories may be needed.
Solution

Example: a robot must insert a key into a lock.

  1. The reward is sparse — the robot only receives reward when the key is successfully inserted.
  2. Exploration is difficult because the robot must discover a precise sequence: reach the key, grasp it, align it, insert it, and turn it.
  3. The gradient estimate has high variance because most trajectories receive zero reward. Occasionally a lucky trajectory gets reward, and the update depends heavily on that rare sample.
  4. Many trajectories are needed because successful behavior is rare. Without enough successful examples, the policy has almost no learning signal.

Exercise 11 — Why Small Policy Updates Matter

Suppose for some state-action pair $\pi_{\theta_\text{old}}(a \mid s) = 0.2$ and after an update $\pi_\theta(a \mid s) = 0.9$. Assume this action had positive advantage.

  1. What is the importance sampling ratio $r_t(\theta)$?
  2. Why might this update be too aggressive?
  3. What does TRPO try to prevent?
  4. What does PPO do instead?
Solution
  1. $$r_t(\theta) = \frac{0.9}{0.2} = 4.5$$
  2. The action went from 20% likely to 90% likely. The data was collected when the action was uncommon, so the old samples may not justify such a large change.
  3. TRPO constrains the KL divergence between the old and new policies, keeping the update in a trust region where old data remains valid.
  4. PPO clips the policy ratio so it stays in $[1-\epsilon, 1+\epsilon]$, preventing extra objective credit for very large probability changes.

Exercise 12 — PPO Clipping Logic

The PPO clipped objective is:

$$L^\text{CLIP}(\theta) = \mathbb{E}\!\left[\min\!\left(r_t(\theta)\hat{A}_t,\;\text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t\right)\right]$$

Suppose $\epsilon = 0.2$, so the ratio is clipped to $[0.8, 1.2]$.

  1. If $\hat{A}_t > 0$, what does the policy want to do to the probability of the action?
  2. If $\hat{A}_t > 0$ and $r_t = 1.5$, what clipped ratio is used?
  3. Why should PPO not keep rewarding increases beyond $1.2$?
  4. If $\hat{A}_t < 0$, what does the policy want to do?
  5. If $\hat{A}_t < 0$ and $r_t = 0.5$, what clipped ratio is used?
  6. Why is the $\min$ used in the PPO objective rather than just the clipped expression?
Solution
  1. The action was better than expected. The policy wants to increase its probability (push $r_t$ above 1).
  2. $r_t = 1.5 > 1.2$, so the clipped ratio is $1.2$.
  3. Encouraging further increases would push the new policy far from the old one. The data came from the old policy, so very large changes may be unreliable.
  4. The action was worse than expected. The policy wants to decrease its probability (push $r_t$ below 1).
  5. $r_t = 0.5 < 0.8$, so the clipped ratio is $0.8$.
  6. The $\min$ makes PPO pessimistic: it takes the lower of the unclipped and clipped objectives. The policy cannot gain extra objective value by moving far from the old policy in either direction.

Exercise 13 — The Core Assumption Behind TRPO and PPO

In one or two sentences: what is the fundamental assumption that policy gradient methods rely on, and what do TRPO and PPO try to enforce?

Solution

Policy gradient methods rely on the assumption that the gradient computed from recent trajectories is a useful local direction for improving the policy — which is only trustworthy if the policy-induced data distribution does not change too much.

TRPO and PPO enforce conservative policy updates so the new policy remains close enough to the old one that old trajectories and advantage estimates are still meaningful.

Part III Scaffolded Derivation Questions

Walk through the key mathematical steps behind policy gradients, baselines, advantages, importance sampling, and PPO. These mirror the derivations in the lecture notes.

Exercise 14 — Deriving the Policy Gradient with the Log Trick

We want to maximize $J(\theta) = \mathbb{E}_{\tau \sim p_\theta(\tau)}[R(\tau)] = \sum_\tau p_\theta(\tau)R(\tau)$.

  1. Take $\nabla_\theta J(\theta)$.
  2. Use the identity $\nabla_\theta p_\theta(\tau) = p_\theta(\tau)\nabla_\theta \log p_\theta(\tau)$ to rewrite the gradient.
  3. Convert the sum back into an expectation.
  4. Recall $p_\theta(\tau) = p(s_0)\prod_{t}\pi_\theta(a_t \mid s_t)P(s_{t+1} \mid s_t, a_t)$. Which terms depend on $\theta$?
  5. Show that $\nabla_\theta \log p_\theta(\tau) = \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)$.
  6. Write the final basic policy gradient expression.
Solution
  1. $$\nabla_\theta J(\theta) = \sum_\tau \nabla_\theta p_\theta(\tau)\,R(\tau)$$
  2. Use $\nabla_\theta p_\theta(\tau) = p_\theta(\tau)\nabla_\theta \log p_\theta(\tau)$:
    $$\nabla_\theta J(\theta) = \sum_\tau p_\theta(\tau)\,\nabla_\theta \log p_\theta(\tau)\,R(\tau)$$
  3. $$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim p_\theta}\!\bigl[\nabla_\theta \log p_\theta(\tau)\,R(\tau)\bigr]$$
  4. Only the policy terms $\pi_\theta(a_t \mid s_t)$ depend on $\theta$. The initial distribution $p(s_0)$ and transition probabilities $P(s_{t+1} \mid s_t, a_t)$ do not.
  5. Take logs: $\log p_\theta(\tau) = \log p(s_0) + \sum_t \log \pi_\theta(a_t \mid s_t) + \sum_t \log P(s_{t+1} \mid s_t, a_t)$. The $\theta$-free terms vanish under $\nabla_\theta$, giving:
    $$\nabla_\theta \log p_\theta(\tau) = \sum_{t=0}^{T-1}\nabla_\theta \log \pi_\theta(a_t \mid s_t)$$
  6. $$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim p_\theta}\!\left[\left(\sum_{t=0}^{T-1}\nabla_\theta \log \pi_\theta(a_t \mid s_t)\right)R(\tau)\right]$$
    This is the basic REINFORCE policy gradient.

Exercise 15 — From Full Return to Reward-to-Go

The basic policy gradient uses $R(\tau)$ for every action. Define the reward-to-go $G_t = \sum_{k=t}^{T-1}\gamma^{k-t}r_k$.

  1. For action $a_t$, which rewards can it affect?
  2. Which rewards can it not affect?
  3. Why should we replace $R(\tau)$ with $G_t$?
  4. Write the reward-to-go policy gradient expression.
Solution
  1. Action $a_t$ can affect rewards $r_t, r_{t+1}, r_{t+2}, \ldots$ — rewards at time $t$ and later.
  2. It cannot affect rewards $r_0, r_1, \ldots, r_{t-1}$ — rewards that already happened.
  3. Earlier rewards are irrelevant to whether action $a_t$ was good. Removing them reduces variance without introducing bias.
  4. $$\nabla_\theta J(\theta) = \mathbb{E}\!\left[\sum_{t=0}^{T-1}\nabla_\theta \log \pi_\theta(a_t \mid s_t)\,G_t\right]$$

Exercise 16 — From Baseline to Advantage

Start from the reward-to-go policy gradient and subtract a baseline $G_t - b(s_t)$.

  1. Why must $b(s_t)$ not depend on the action $a_t$?
  2. Set $b(s_t) = V^\pi(s_t)$. What does $G_t - V^\pi(s_t)$ estimate?
  3. What is the advantage function $A^\pi(s,a)$?
  4. Write the policy gradient using the advantage.
Solution
  1. If the baseline depends on the action, it can change the expected policy gradient. When $b$ depends only on the state:
    $$\mathbb{E}_{a \sim \pi(\cdot \mid s)}\!\bigl[\nabla_\theta \log \pi_\theta(a \mid s)\,b(s)\bigr] = 0$$
    so subtracting it leaves the expectation unchanged.
  2. $G_t - V^\pi(s_t)$ estimates how much better or worse the observed return was than the expected return from state $s_t$. This is the advantage.
  3. $$A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$$
  4. $$\nabla_\theta J(\theta) \approx \mathbb{E}\!\left[\sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\,\hat{A}_t\right]$$

Exercise 17 — Importance Sampling and the PPO Ratio

The importance sampling identity states $\mathbb{E}_{x \sim p}[f(x)] = \mathbb{E}_{x \sim q}\!\left[\frac{p(x)}{q(x)}f(x)\right]$.

  1. In PPO, what plays the role of $p$?
  2. What plays the role of $q$?
  3. Write the policy ratio $r_t(\theta)$.
  4. Why does this ratio allow us to use data from the old policy?
  5. Why can this ratio become dangerous?
Solution
  1. The new policy $\pi_\theta$ plays the role of $p$.
  2. The old policy $\pi_{\theta_\text{old}}$ plays the role of $q$.
  3. $$r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_\text{old}}(a_t \mid s_t)}$$
  4. The ratio reweights the old data to correct for the fact that it was sampled under a different policy. This lets us evaluate or improve the new policy without re-collecting trajectories.
  5. If the ratio is very large or small, a few samples can dominate the gradient estimate, causing high variance and potentially a policy update that is too large.

Exercise 18 — Deriving the PPO Clipped Objective

Start from the importance-weighted objective $L(\theta) = \mathbb{E}[r_t(\theta)\hat{A}_t]$. PPO clips the ratio to $\text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)$.

  1. If $\hat{A}_t > 0$, do we want $r_t$ to increase or decrease?
  2. Why should we stop rewarding the objective once $r_t > 1+\epsilon$?
  3. If $\hat{A}_t < 0$, do we want $r_t$ to increase or decrease?
  4. Why should we stop rewarding the objective once $r_t < 1-\epsilon$?
  5. Explain why PPO uses $\min(r_t \hat{A}_t,\;\text{clip}(r_t,1{-}\epsilon,1{+}\epsilon)\hat{A}_t)$ rather than just the clipped expression alone.
Solution
  1. If $\hat{A}_t > 0$, the action was better than expected, so we want to increase its probability — push $r_t$ above 1.
  2. Rewarding further increases beyond $1+\epsilon$ would encourage the policy to move too far from the old policy, where the data may no longer be valid.
  3. If $\hat{A}_t < 0$, the action was worse than expected, so we want to decrease its probability — push $r_t$ below 1.
  4. Rewarding further decreases below $1-\epsilon$ would again push the policy too far, making updates too aggressive.
  5. Using only the clipped expression would also clip updates that are not harmful. The $\min$ is pessimistic: it keeps the normal objective when the update is safe, and switches to the clipped (lower) value when the update tries to go too far. The policy cannot gain extra credit from large probability changes in either direction.
    $$L^\text{CLIP}(\theta) = \mathbb{E}\!\left[\min\!\left(r_t(\theta)\hat{A}_t,\;\text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t\right)\right]$$

Exercise 19 — Rare Rewards and High Variance

Suppose a robot receives reward only when it visits one rare state-action pair $(s^\star, a^\star)$. Otherwise, reward is zero. The REINFORCE estimator is $\hat{g} = \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\,G_t$.

  1. What happens to $G_t$ for most trajectories?
  2. What happens to the gradient estimate for most trajectories?
  3. What happens on the rare trajectory that gets reward?
  4. Why does this create high variance?
  5. Why is exploration especially important in this setting?
Solution
  1. For most trajectories the robot never reaches $(s^\star, a^\star)$, so all rewards are zero and $G_t = 0$.
  2. If $G_t = 0$, the gradient contribution $\nabla_\theta \log \pi_\theta(a_t \mid s_t)\cdot G_t = 0$. Most trajectories give no learning signal.
  3. On a rare successful trajectory $G_t$ is positive, producing a large nonzero policy gradient update.
  4. Most gradient estimates are zero, but a few rare estimates are large. The learning signal is inconsistent and depends heavily on rare lucky trajectories — that is high variance.
  5. Exploration is essential because the robot must discover $(s^\star, a^\star)$ before it can learn from it. If the policy never visits that pair, the reward is forever invisible.
